# 🤝 comrade - Share Your Terminal in Seconds

## 🚀 What is comrade?

comrade is a free tool that lets you share your computer's terminal (command prompt) with another person over the internet. Think of it as a "screen share" but for the text-based command line. It works directly between two computers—no middleman server is needed.

This is perfect when you need a friend, colleague, or tech support person to see what you're typing or help you fix something on your computer. You stay in control—you decide who gets access and when to end the session.

## ✨ Key Features

- **Direct Connection** – Your computers talk to each other directly, so your data doesn't pass through a third-party server.
- **No Account Required** – No sign-ups, no emails, no passwords. Just download, run, and share.
- **Works Across the Internet** – Even if you and your partner are on different networks, comrade finds a way to connect.
- **Secure by Design** – The connection is encrypted, and only the person with your unique session code can join.
- **Cross-Platform** – Works on Windows, macOS, and Linux.
- **Lightweight** – Small download, runs quietly in the background, and uses minimal system resources.
- **Session Control** – You can end the shared session at any time with a single command.

## 🛠️ How to Use comrade

### Starting a Session

1. Run comrade on your computer.
2. Note the session code displayed.
3. Share the code with your partner.
4. Wait for them to connect.

### Joining a Session (as the helper)

1. Run comrade on your computer.
2. When prompted, enter the session code you received.
3. You'll be connected to the other person's terminal.

### Ending a Session

- Type `exit` in the terminal, or
- Close the comrade window.

The session ends immediately, and no one can reconnect without starting a new session.

## ❓ Frequently Asked Questions

### Is comrade safe to use?

Yes. comrade creates a direct, encrypted connection between two computers. Your session code acts like a key—only someone with that exact code can join. No data is stored on any server.

### Do I need to be technical to use it?

Not at all. If you can double-click a file and copy-paste a code, you can use comrade. The terminal looks intimidating, but you don't need to understand it—just share the code and let your partner handle the commands.

### What if my partner is on a different operating system?

No problem. comrade works across Windows, macOS, and Linux. The experience is identical on all platforms.

### Can someone access my files without permission?

No. comrade only shares the terminal window—not your file explorer, browser, or other applications. Your partner can only type commands in that one terminal session, and you can end it anytime.

### What happens if my internet disconnects?

The session will close. Simply restart comrade and share a new session code to reconnect.

## 🔧 Troubleshooting

### The application won't start

Make sure you downloaded the correct file for your operating system. On Windows, right-click the `.exe` file and select "Run as administrator" if you see an error.

### My partner can't connect

Double-check that you're sharing the exact session code (including any hyphens). Also confirm both computers have an active internet connection.

### The connection is slow

This is rare, but if it happens, try closing other programs that use the internet heavily, like video streaming or large downloads.

## 📚 Advanced Tips (For the Curious)

comrade uses modern peer-to-peer technology (DHT, ICE, STUN) to establish connections even behind firewalls. It's built on the same principles as popular tools like tmate and tmux but with a focus on simplicity and direct communication.

If you're familiar with SSH, comrade provides a similar experience without needing to configure servers or ports.
